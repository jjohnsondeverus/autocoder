  <overview>
    <purpose>
      Build a full-stack web application that wraps Anthropic's autonomous coding agent harness,
      providing a visual dashboard for creating projects, managing features, controlling agent
      execution, and monitoring progress in real-time.
    </purpose>

    <what_you_are_building>
      You are building the UI/wrapper layer - a FastAPI backend + React frontend that:
      - Provides a web-based project management dashboard
      - Allows users to create projects with AI-assisted spec generation
      - Manages a database of features/test cases for each project
      - Controls agent subprocess execution (start/stop/pause/resume)
      - Streams agent output to the UI in real-time via WebSocket
      - Displays feature progress on a visual kanban board
    </what_you_are_building>

    <what_you_are_reusing>
      You will REUSE the core agent harness from Anthropic's quickstart:
      https://github.com/anthropics/claude-quickstarts/tree/main/autonomous-coding

      The core harness includes:
      - autonomous_agent_demo.py - CLI entry point with argument parsing
      - agent.py - Agent session loop using Claude Agent SDK
      - client.py - SDK client configuration with security settings
      - security.py - Bash command allowlist validation
      - prompts.py - Prompt template loading
      - progress.py - Basic progress tracking utilities

      These files implement the "two-agent pattern" (Initializer + Coding agents) and handle
      all Claude API communication. Your wrapper will orchestrate these as subprocesses.
    </what_you_are_reusing>

    <learning_goals>
      Building this project will teach you:
      - How to orchestrate long-running AI agent processes from a web app
      - Full-stack development with FastAPI (Python) and React (TypeScript)
      - Real-time communication via WebSocket for streaming agent output
      - Subprocess management and process lifecycle handling
      - Database design for task/feature tracking
      - MCP (Model Context Protocol) server development
      - Security considerations for AI-powered applications
    </learning_goals>

    <data_flow>
      <project_creation>
        1. User fills out project creation form in React UI
        2. Frontend POST to /api/projects with name + path
        3. Backend creates project directory structure
        4. Backend registers project in global registry database
        5. Backend scaffolds prompt templates to project/prompts/
        6. UI receives success, updates project list
      </project_creation>

      <agent_execution>
        1. User clicks "Start Agent" in UI
        2. Frontend POST to /api/projects/{name}/agent/start
        3. ProcessManager spawns subprocess: python autonomous_agent_demo.py --project-dir ...
        4. ProcessManager captures stdout/stderr
        5. ProcessManager broadcasts output lines via WebSocket
        6. React UI receives WebSocket messages, updates log viewer
        7. Agent uses MCP tools to query/update features.db
        8. UI polls /api/projects/{name}/features for kanban updates
      </agent_execution>

      <real_time_updates>
        WebSocket message types:
        - "progress" - Feature completion stats { passing: N, total: M }
        - "agent_status" - Status changes { status: "running"|"paused"|"stopped"|"crashed" }
        - "log" - Agent output line { message: "...", timestamp: "..." }
        - "feature_update" - Feature status change { feature_id: N, passes: true }
      </real_time_updates>
    </data_flow>
